# Patch 105 — Quarterly auto-audit cron

Adds a GitHub Action on a quarterly schedule that runs Playwright + axe + Lighthouse against the **production URL** (`https://skedaddleinc.com`) and writes a markdown findings file to `docs/superpowers/audits/YYYY-MM-DD-auto-audit.md`. Forces a re-audit cadence so the same class of mobile / a11y / perf regressions doesn't reappear in new components.

The bot opens a PR with the audit file attached — admin reviews and merges.

## Branch

`quarterly-audit-cron`

## Scope

**Create:**
- `.github/workflows/quarterly-audit.yml`
- `scripts/run-quarterly-audit.mjs`

## Tasks

- [ ] **Step 1: Workflow file**

```yaml
name: Quarterly auto-audit
on:
  schedule:
    # 00:00 UTC on the 1st of every 3rd month — Jan / Apr / Jul / Oct
    - cron: '0 0 1 1,4,7,10 *'
  workflow_dispatch: {}  # allow manual triggering

jobs:
  audit:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20', cache: npm }
      - run: npm ci
      - run: npx playwright install --with-deps chromium
      - run: node scripts/run-quarterly-audit.mjs
      - name: Open PR with audit findings
        uses: peter-evans/create-pull-request@v6
        with:
          token: ${{ secrets.GITHUB_TOKEN }}
          branch: auto/quarterly-audit-${{ github.run_id }}
          base: main
          title: 'Quarterly auto-audit — please triage'
          body: |
            Auto-generated audit. Review the markdown file in `docs/superpowers/audits/`
            and either:
            - Open follow-up issues for actionable findings, then merge this PR, OR
            - Close this PR if everything is noise

            Generated by `.github/workflows/quarterly-audit.yml`.
          add-paths: docs/superpowers/audits/
          commit-message: 'chore: quarterly auto-audit findings'
```

- [ ] **Step 2: The script**

`scripts/run-quarterly-audit.mjs`:

```js
/**
 * Quarterly auto-audit. Runs Playwright (visual snapshot diff vs committed
 * baselines), axe-core (WCAG violations), and Lighthouse (perf + a11y +
 * best-practices) against production. Writes findings to a dated markdown
 * file in docs/superpowers/audits/.
 */
import { execSync } from 'node:child_process'
import { writeFileSync, mkdirSync } from 'node:fs'
import { resolve } from 'node:path'

const today = new Date().toISOString().slice(0, 10)
const outDir = resolve('docs/superpowers/audits')
const outPath = resolve(outDir, `${today}-auto-audit.md`)
mkdirSync(outDir, { recursive: true })

const sections = []
sections.push(`# Quarterly auto-audit — ${today}\n`)
sections.push('Auto-generated. Triage findings into follow-up issues or close the PR.\n')

// --- Playwright (visual + a11y) ---
sections.push('\n## Playwright visual + a11y\n')
try {
  const out = execSync('npm run test:visual 2>&1 || true', { encoding: 'utf8' })
  sections.push('```\n' + out.slice(-4000) + '\n```\n')
} catch (e) {
  sections.push(`Playwright failed: ${e.message}\n`)
}

// --- Lighthouse ---
sections.push('\n## Lighthouse (mobile preset)\n')
const ROUTES = ['https://skedaddleinc.com/', 'https://skedaddleinc.com/tires', 'https://skedaddleinc.com/orders']
for (const url of ROUTES) {
  try {
    const out = execSync(`npx lighthouse "${url}" --quiet --chrome-flags="--headless" --preset=desktop --output=json --output-path=stdout`, { encoding: 'utf8' })
    const json = JSON.parse(out)
    const scores = {
      perf: Math.round(json.categories.performance.score * 100),
      a11y: Math.round(json.categories.accessibility.score * 100),
      best: Math.round(json.categories['best-practices'].score * 100),
      seo: Math.round(json.categories.seo.score * 100),
    }
    sections.push(`### ${url}\n- Performance: ${scores.perf}\n- Accessibility: ${scores.a11y}\n- Best practices: ${scores.best}\n- SEO: ${scores.seo}\n`)
  } catch (e) {
    sections.push(`### ${url}\nLighthouse error: ${e.message}\n`)
  }
}

writeFileSync(outPath, sections.join('\n'), 'utf8')
console.log(`Wrote ${outPath}`)
```

## Dependency note

If PR-A (testing foundation, `npm run test:visual` script) has not merged when this brief is dispatched, the script's Playwright step will skip silently (npm script returns non-zero). That's fine — the Lighthouse section still produces value. Once PR-A merges, the next quarterly run will include Playwright output automatically.
